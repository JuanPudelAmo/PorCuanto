⚙️ Conectar APIs — opcional

PorCuanto funciona sin APIs usando búsqueda pública. Las APIs añaden datos más directos y fiables.
Comprobando configuración…
1 · OpenAI (para analizar fotos)

Crea una API key en la plataforma de OpenAI y configúrala en el servidor como OPENAI_API_KEY.

Abrir API Keys de OpenAI ↗

Importante: la suscripción ChatGPT y la API tienen facturación separada. Tener ChatGPT Go/Plus/Pro no convierte automáticamente la suscripción en saldo de API.

2 · Keepa (Amazon)

Crea una cuenta en Keepa, contrata/activa un plan API y copia tu API key. Configúrala como KEEPA_API_KEY.

Abrir Keepa API ↗

Keepa usa un sistema de tokens para sus consultas. Puedes usarlo para precios, historial, ofertas y datos de vendedores.

3 · eBay (comparables)

Crea una aplicación en eBay Developers → Application Keys → Production. Copia App ID (Client ID) y Cert ID (Client Secret) y configúralos como EBAY_CLIENT_ID y EBAY_CLIENT_SECRET.

Abrir eBay Application Keys ↗

Para búsquedas del Browse API se usa un Application access token; PorCuanto lo genera automáticamente con OAuth.

4 · ¿Dónde pongo las claves?

En el archivo .env del servidor:

OPENAI_API_KEY=tu_clave
KEEPA_API_KEY=tu_clave
EBAY_CLIENT_ID=tu_client_id
EBAY_CLIENT_SECRET=tu_client_secret

No pongas las claves dentro del HTML ni las compartas públicamente.
